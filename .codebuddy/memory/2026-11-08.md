## 企微推送正文改取 summary

**问题**：`scripts/analyze-video.js` 的李大霄企微推送原为
`pushWechat(title, bvid, analysisJson.structured?.operation_advice)`。
提示词改版后 `operation_advice` 已降级为 `advice_literal` 的**兼容字段**，值是"他明说的操作原话"，
实测推送出来常是「做个好人」「原文未提及」「做个好人，做个好人，星星之火也能温暖他人」。
字段名、类型都没变（纯语义漂移）⇒ 一直不报错，直到人看到企微消息才发现。

**改动**（仅 `scripts/analyze-video.js`）
- 新增纯函数 `buildWechatContent(title, bvid, entry)`：正文优先 `summary`，为空回退 `operation_advice`，再回退「暂无摘要」。
- 附一行 `> 市场：…｜方向：…｜情绪：N/100`（`market` 映射中文标签）。理由：新口径下"讲哪个市场"是关键信息，不写出来读者会把「美股看空」当成「A股看空」。
- 可选「原话要点」行：仅**新口径条目**（有 `market`）才加；旧条目的 operation_advice 是模型推断，标成"原话"会误导。用正则剔除安抚套话（做个好人 / 星星之火也能温暖 / 人心定能换得人心 / 怒涨）后，实质内容 ≥8 字才显示。
- `pushWechat` 改为接收整条 `entry`；调用处同步改。
- 新增 CLI `--preview-push [BV号]`：本地打印将推送的文案，**不发送**，便于验证文案改动。

**验证**：`--preview-push BV1vG4666E57` 正确过滤掉安抚套话；`--preview-push BV1XC4n6mEpG` 保留「下次别借钱咯；多打几份工…」等实质原话。`node --check` 与 lint 均通过。

**注意**：企微推送只在处理**新视频**时触发，`--reanalyze` 不推送，所以历史重跑不会刷屏。
`build-views-lite.js` 与 `notifyScoring` 仍取 `operation_advice` 给工作台 —— 若工作台卡片也展示"操作建议"，可能有同样的语义漂移，本次未改。

## 评估：是否开启 LLM 深度思考模式（结论：不建议）

用户问"输出是不是太浅显、要不要开 thinking"。**未改代码，只做评估。**

**量化（当前 videos.json：新口径 139 条 / 旧 396 条）**
| 维度 | 新 | 旧 |
|---|---|---|
| hidden_meanings 条数 | 0.1 | 4.6 |
| signals 条数 | 2.3 | 6.0 |
| logic_pieces 条数 | 1.8 | 3.0 |
| final_conclusion 字数 | 162 | 323 |
| core_views 条数 | 7.4 | 7.1 |
| core_views 总字数 | 199 | 265 |

新口径字段填充率 139/139（market / market_literal / direction / confidence / sentiment_note / sentiment_by_market / code_words / disclaimer_stacking / transcript_ref / summary）。

**关键对照**：抽样「调整的原因」原文 1087 字 → `core_views` 8 条 + `data_analysis.points` 16 条，原文里的 17 个数据点（1276亿、262亿、87亿、634亿、649亿、10.05%、1.4%、0.57%、13%、1.7%、0.59%、2.84%、0.26%、1.08%、4.93%、4.99%、5.32%）几乎全部抓到 ⇒ **字面提取并不浅，浅的是被刻意砍掉的推断字段**。

**输入才是上限**：138 条有原文存档，min 233 / 中位 1081 / max 2831 字。B站 AI 字幕疑似片段化（5~15 分钟视频通常 >2000 字），思考无法补出原文没有的信息，只会补出编造的信息。

**项目已有实测（`scripts/utils/llm.js` 注释，11-07）**
- 基线 / `enable_thinking:false` → reasoning 吃满 16384 token、180 秒、`content` 空；
- `thinking:{type:'disabled'}` 或 `reasoning_effort:'none'` 才有效（rtok=0、1.6 秒、JSON 正常）；
- `glm-5.3` / `sensenova-6.8-flash` 是推理模型，长提示词下 content 恒空；`reasoning_effort:'minimal'` 也吃满额度；
- 现成开关 `LLM_ENABLE_THINKING=1`（默认关），`LLM_JSON_ATTEMPTS` 默认 5。

**结论**：开思考会重新引入"弦外之音"，与"字面为主干"方向相反，并复发刚修好的 JSON 截断问题。
**若真要加深，优先级**：① 补输入（字幕完整性 / whisper 兜底）＞ ② 给 `core_views` 每条加 `quote`，让"深度"可被脚本验证 ＞ ③ 离线单条允许 thinking，只用于 R1 免责堆叠判定复核，结果写独立字段不污染主流程。
**验收口径**：真开了就复测字面 2-gram 重合率（当前 49.1%，旧 22.7%）、未表态占比、A股方向分布；重合率下降即说明模型开始编。
